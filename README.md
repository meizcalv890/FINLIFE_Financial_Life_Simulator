# FINLIFE v2.0 — Financial Life Simulator

FINLIFE is a lightweight browser game about everyday money decisions.

This version separates the original single-file implementation into
maintainable files while keeping the original game flow and bilingual
scenarios.

## Features

- 30-day financial simulation
- Initial money: Rp1,000,000
- Savings target: Rp1,000,000
- Random financial events
- Yes/No decision system
- Cash and savings tracking
- Savings progress bar
- Indonesian and English language support
- Background music
- Sound effects
- Pause and resume
- Game result screen
- Local game history
- Responsive interface
